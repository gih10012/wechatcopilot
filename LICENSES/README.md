# Dependency licenses

The repository itself is MIT licensed; see `../LICENSE`.

`allowed.txt` is the source-dependency license allowlist enforced in CI. It permits common permissive licenses plus MPL-2.0 for file-scoped copyleft dependencies. Adding a dependency under another license requires maintainer review, updated notices, and an explicit policy change.

Release SBOMs are the authoritative inventory for a built artifact. Official WeChat and WeCom clients are not project dependencies or distribution artifacts and are never covered by this directory.
